# 薪火自动接单助手

适用于 [薪火任务广场](https://xinhuo123.com/tasks) 的 Chrome MV3 扩展，用于自动检测可接任务、接取评论类订单、打开目标 X 推文、生成并提交回复，并在薪火官方核验后继续下一单。

## 功能

- 自动扫描薪火任务广场，过滤任务类型、档位、额度、赏金和倒计时状态。
- 支持当前任务进入最后 5 秒抢单窗口。
- 接单后等待薪火自动打开目标 X；未自动打开时补开精确推文页。
- 在 X 页面执行关注、点赞、回复和任务组件提交流程。
- X 提交后回到薪火订单详情，只读取官方提交结果，不重复提交。
- 任务完成后自动返回任务广场继续检测。
- 任务广场连续 5 分钟没有进展时，停止当前运行、刷新页面并重新执行全量检测。
- 当前运行窗口内的重复薪火任务广场标签页会自动合并为一个，其他窗口不主动关闭。
- 侧边栏提供详细运行日志、回复记录、调试步骤和配置管理。

## 安装

1. 解压发布包。
2. 打开 Chrome 的 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目目录。
5. 打开薪火和 X，并点击扩展图标打开侧边栏。

## 配置

在侧边栏中设置：

- 运行时间段、最低任务赏金、轮询间隔。
- 单次任务上限、接单尝试上限和锁定超时。
- X 回复模式和薪火自动提交。
- AI 模型名称、Responses API 地址、API Key 和系统提示词。

默认 AI 模型为 `gpt-5.6-terra`。自定义 API 地址应使用 HTTPS，并填写兼容 Responses API 的接口地址，例如 `https://.../v1/responses`。

## 自动流程

```text
薪火任务广场扫描
  -> 过滤可接任务
  -> 打开任务详情
  -> 接取并确认风险提示
  -> 打开目标 X 推文
  -> 执行 X 互动与回复
  -> 提交 X 任务组件
  -> 回到薪火订单详情核验
  -> 返回任务广场
```

薪火平台与 Lighthouse 的确认页面不同，扩展不会直接套用 Lighthouse 的完成判断。已接取订单的后续步骤失败时会保留当前订单并停止扫描，避免误接新单或造成串单。

## 本地检查

项目没有 npm 构建步骤，使用 Node.js 运行检查：

```bash
node tests/behavior-check.mjs
node tests/review-check.mjs
node tests/regression-check.mjs
```

也可以检查全部 JavaScript 语法：

```bash
find src tests -type f \( -name '*.js' -o -name '*.mjs' \) -print0 | xargs -0 -n1 node --check
```

## 权限与安全

扩展需要访问薪火、X、浏览器标签页、存储、脚本注入和定时器权限，以完成自动任务流程。API Key 仅保存于扩展本地存储；不要把包含 API Key 的配置、截图或日志提交到公开仓库。
