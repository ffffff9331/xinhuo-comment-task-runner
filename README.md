# 薪火自动接单助手

当前版本：**0.1.51** · Chrome Manifest V3 扩展。

[下载最新版 ZIP](https://github.com/ffffff9331/xinhuo-comment-task-runner/archive/refs/heads/main.zip) · [GitHub 仓库](https://github.com/ffffff9331/xinhuo-comment-task-runner)

适用于 [薪火任务广场](https://xinhuo123.com/tasks)，配合已登录的薪火和 X 账号使用。

## 能做什么

- 按当前等级、任务类型、最低赏金和平台倒计时筛选可接任务。
- 接取评论类任务后打开目标 X 推文，按本单要求执行互动、生成回复和提交任务组件。
- 用完整推文编号核对 X 目标；同一推文从 `i/status` 跳转到作者链接后继续本单，跨链接去重，保留订单、窗口与运行身份保护。
- 回到薪火核对本单官方结果；确认完成后，按运行设置继续扫描。
- 提供全量检测、从指定步骤接管、停止运行、运行日志和回复历史。
- 保存模型、提示词与 API Key；浏览器重启或扩展重载后仍保留配置。

## 首次安装

1. 下载上方 ZIP，解压到固定目录，之后不要随意移动该目录。
2. 打开 Chrome 的 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的目录**，不要选择 ZIP 或外层目录。
4. 登录薪火和 X，完成网站要求的账号连接；若网站要求连接薪火官方助手，按网站提示完成。
5. 点击扩展图标打开侧边栏，在“设置”中填写配置并保存。

## 配置

- **AI 模型**：默认 `gpt-6.1-sol`，可填写中转站支持的其他模型名称。已保存的模型不会强制覆盖；需要切换时填写 `gpt-6.1-sol` 并保存。
- **API Key**：填写现有中转站的 Key。AI 回复固定使用 `https://api.vayne.cc.cd/v1/responses`，当前界面不提供地址或协议切换。
- **系统提示词**：可自行修改回复要求。
- **回复模式**：选择仅填入或自动发送；是否自动提交任务由对应开关控制。
- **运行限制**：可设置运行时段、最低赏金、单次任务上限、接单尝试上限、轮询间隔和接单超时。

需要完整自动执行时，检查“自动发送”和“回复后自动提交任务”的设置。仅填入模式需要人工继续。
配置保存失败会显示原因，并阻止本次启动；请先处理错误再重试。

## 使用

**全量检测**：从任务广场开始扫描，接单后依次处理 X 互动、任务提交和薪火结果核验。达到任务上限、尝试上限或运行时段限制时，按设置结束或等待。

**单步流程**：点击第 1～7 步中的某一步，会接管并从该步连续执行后续步骤；请根据当前页面和订单选择步骤。完成本单后，满足自动运行配置时会交回自动循环。

**停止当前运行**：取消本轮流程和排队步骤，清空本轮订单状态、未知动作记录、临时去重和运行日志，保留设置、API Key 和已完成历史。停止后不会自行继续，需再次点击全量检测或流程步骤。

停止只清理插件本地状态，不能撤销已经发送给薪火或 X 的操作。若停止前已经接单或发出评论，请先核对网站结果，再启动下一轮。
“记录”页的“清空记录”会删除回复历史，与停止运行不同。

## 更新已安装版本

1. 等当前订单结束；若存在结果未知订单，先在网站核对，不要靠更新来清除它。
2. 点击“停止当前运行”，下载并解压最新 ZIP。
3. 用解压后的文件覆盖**原安装目录**中的对应文件，保持 `manifest.json` 所在目录不变。
4. 打开 `chrome://extensions`，在原来的扩展卡片上点击“重新加载”。
5. 刷新已打开的薪火和 X 页面，再打开侧边栏核对版本与设置。

保留同一 Chrome 用户配置、同一扩展和同一安装目录，以保留本地 Key 与历史。不要先卸载再安装，也不要重新加载成另一个扩展。

## 等待、失败和订单保护

- 平台放号倒计时、限速、额度或等级限制属于平台状态；倒计时仍在走不表示插件卡死。
- 明确未接到单时返回任务广场继续扫描；平台给出的临时等待按到期时间处理，不能把所有失败都视为可以立即重试。
- 接单、评论或提交结果未知时保留当前订单并停止继续接新单，避免重复操作；恢复时先核对同一订单。
- 5 分钟刷新只在自动模式仍处于扫描阶段、没有当前订单且没有结果未知动作时触发，不是所有页面每 5 分钟刷新。
- 完成以薪火当前订单的官方结果为准。提交过、按钮消失或日志显示已发送，都不能单独证明奖励到账。

## API Key 与本地数据

Key 保存在受限的 `chrome.storage.local` 独立项中，仅扩展可信页面和后台可读取；普通设置、运行状态和发送给页面脚本的消息不包含 Key。
密码输入框只遮挡显示，**不是加密存储**；后台会使用 Key 向上方 AI 中转站发起请求。

重启浏览器、重载或按上述方式更新扩展后，已保存的 Key 会保留。要删除 Key，请清空输入框并保存；主动清空后不会被旧设置恢复。
旧版本尚存的 Key 会尝试迁移；0.1.49 的会话 Key 如果已经随重启或重载丢失，需要重新输入并保存一次。
缺少 Key 时不能自动接取需要 AI 回复的任务；已知不需要 AI 的互动单步和已有订单核验仍可按其条件执行。
